# Raupo Irrigation Lookup

Fast, offline-ready mobile web lookup for translating Raupo vineyard Hunter Blocks, valve stations, and whiteboard shorthand into physical valve locations and outer row boundaries.

**Live App:** https://orestesnz.github.io/Irrigation/

## Features

- **Hunter Block Lookup (1–23):** Select a Hunter controller block to view its grouped vineyard blocks, assigned valves, physical row locations, outer row limits, and Young Vine (YV1–YV3) mappings.
- **Valve / Station Lookup (1–36, excluding V34):** Look up any individual station to check its exact valve location, outer rows, and clone/sub-block details.
- **Whiteboard / Shorthand Decoder:** Paste or type daily whiteboard codes (e.g., `LOU1`, `OSI7`, `WILVI`, `FIN YV`, `LAN2`) to decode matching valves and flag block crossovers or ambiguities.
- **Field-Ready Design:** Single-file `index.html` with high-contrast styling for bright sunlight and offline browser caching once loaded.

## Usage
